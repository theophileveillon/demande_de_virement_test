Note De Frais

Une NDF permet UNIQUEMENT de rembourser un membre de l'AEn7. Les tickets de carte, les screen de compte bancaire ou les "jte jure j'ai payé", ne permettent pas de créer une NDF

Déclaration Sur l'Honneur

Attention une DSH n'est valable que si aucun justificatif n'est obtenable par aucun moyen comme sur les sites de seconde main par exemple. Vous pouvez demander un ticket de caisse à une entreprise, elle est obligée de conserver une trace de votre paiement.

Facture

Attention, un Devis (même signé) n'est pas une facture, tout prestataire est dans l'obligation de vous fournir une facture si vous lui demandez. Nous vous conseillons de garder un exemplaire de toutes les factures de votre bureau ou club dans vos dossiers pour garder une bonne trace de votre trésorerie.
